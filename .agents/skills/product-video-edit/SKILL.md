# 真人产品视频剪辑（V5.1 硅谷101精品标准）

本技能是实拍口播与科技商业解说长片的制作与返修入口。分镜、口播、声音和审片由本流程决定，画面、动效、可编辑时间线和渲染由 OpenMotion 承担。若面对已拍完口播或新选题的 5–15 分钟科技解说长片，需先做“从零写稿 / 台词只删不改、对标硅谷101设计分镜、判断生成清单并输出飞书审定”，先执行同仓库 `wlj-script-rewrite` 技能，待脚本拍板后再进入本技能实剪。

## 从大纲到实剪（严禁偷懒缩水）

1. **先读大纲、看全量源片。** 把所有实拍 A-roll 与 B-roll 生成缩略图总览并逐条审看，查清每句口播是否有 NG 重录、是否有未使用的高清实拍镜头（全片严禁重复使用同一条 B-roll）。实拍缺的通用画面先从网上找无字幕干净素材；缺结构剖面图或风格垫图主动调用 **Nano Banana / Imagen（`image-generator`）** 生成，不主动安排补拍。
2. **出制作脚本，审定后再动工。** 保留台词原意，注明取用文件与精确源时间，字段与视觉规范见[制作分镜](references/shot-plan.md)。脚本未经用户审定前，不擅自渲染成片或提交付费视频生成。
3. **4K 原生音画同源口播精剪（零嘴型误差、零 NG 拼句、零长气口、零跳帧）。**
   - **音画同源原子切片**：严禁把重剪后的纯音频与原视频分开独立对位！口播音频与所有真人出镜 `<video>` 必须从**同一条原生音画同步的 4K 相机母带**按 `1600 samples/frame @ 48kHz / 30fps` 整数采样对齐同源切出，出镜子片段统一用短 GOP（`-g 15 -keyint_min 1 -bf 0`）编码，彻底杜绝嘴型差半拍。
   - **NG 重录只取最后完整遍**：当主播前面说了两句发现说错、随后从头重录时，**严禁把前面废片的前两句和后面重录的后半截掐头拼接**（会产生严重语气分裂感），一律直接采用**最后一次完整干净的重录版**。
   - **紧凑自然气口**：按写作语义连贯度收紧气口——同句内分句 `0.06–0.14s`（`2–4` 帧），句末换气 `0.20–0.23s`（`6–7` 帧），严禁在连贯段落中间留超过 `0.3s` 的死静音；尾字收音后若原片有低头/复位动作，必须**在复位发生前切进章节卡或 B-roll**。
   - **补录跳帧光学缩放遮蔽**：因为口播常按单句补录拼接，相邻两段真人镜头若存在补录接缝，必须利用 4K 原片做 **`1.0x` 全景 ↔ `1.3x` 光学近景交替切换**（或切 B-roll），严禁同景别硬接出现人物跳帧。
4. **分段精制 + 开头试剪定手感。** 长片强烈建议按章节拆分为独立 OpenMotion 子工程（如 `seg0`..`seg4`）分段制作渲染，把算力与细节打磨全部集中在每一章的每个镜头上；先做开头一段确认手感，再推进全章，最后通过 `48kHz` 整数采样全局连续母带 + `0.40s` 光学推镜模糊叠化（`xfade`）丝滑合成全片（**严禁章节间黑屏硬拼**）。操作细节见[本机制作](references/local.md)。

## 视觉和声音铁律

- **现代商业隐喻生成管线**：能用实拍和真实史料的绝不用生成糊弄；原理拆解上 `#0E0F12` 动态画布（不透明深底标签防连线穿字、`<canvas>` 动态波束、超过 `3s` 的结论拆为多幕动态数据看板，严禁黑底大字干等 `5–8s`）；比喻与情绪镜头需生成时，**必须先用 Nano Banana / Imagen 生成现代商业风参考图锁定美术质感（严禁在 LibTV 里生图），再送入 LibTV `magi-2`（硬锁定唯一视频模型）生成现代商业隐喻视频**（如 `0101` 光纤代码水龙头、暗调建筑光廊声波→文字板→声浪三棒转化，严禁字面直译厨房自来水或卡通机器人递棒子）。
- **零底纹花字、无标点字幕与全篇常驻条**：
  - 包装大字一律强制 **`text-shadow: none !important; filter: none !important;`**（严禁花字底下留黑色阴影脏底纹），多字标题加 `white-space: nowrap` 严禁折行孤字。
  - 底部 `42px` 章节条从 `00:00` 第 `0` 帧到全片尾帧**全程常驻不隐藏**（含 `导语` 与连续进度条）；涉及年代演进配顶部 `#sv-era-tree` 演进节点树；左上来源标留足安全边距 `top: 38px; left: 48px`；字幕去句尾标点、句中逗号改单空格。
- **零半途冻帧与差异化音效**：每条 `<video>` 真实时长必须严格大于 `data-duration`，严禁话没念完画面先卡停；定格解读必须在 `0ms` 定格帧同步触发视觉包装；全片配多变体差异化拟音与 UI 音效，严禁单一音效重复刷屏。

## 聊天审片与四道硬核验

- 默认用对话、截图或口头描述收反馈；用户说「先不急着改 / 先复核思考总结」时，严格先做全量排查与反思方案汇报，等明确指令再动工。
- 新版导出交付前必须跑通**四道硬核验**：
  1. **全片出镜口播互相关音画同步校验**（对比 4K 原始相机音轨，全片误差必须 `< 10ms`）；
  2. **OpenMotion `lint-project.mjs` 零报错校验**（GSAP 位移纯用 `x`/`y`/`scale` GPU 变换，禁用 `left`/`top`）；
  3. **24 帧全片关键镜头与章节接缝抽帧目视核验**（重点查花字无底纹、无折行孤字、无连线穿字、左上来源标无裁切、章节接缝无黑屏）；
  4. **`ffmpeg blackdetect` 零中段黑屏与 `volumedetect` 响度核验**（均值约 `-16 dB`）。
