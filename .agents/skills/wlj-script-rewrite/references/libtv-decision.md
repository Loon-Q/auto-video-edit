# LibTV / MAGI-2 生成判断

提示词写法、调用纪律与脚本细节见 `guizang-magi2-skill`（`~/.gemini/config/skills/guizang-magi2-skill/`）。

## 决策表
| 判断 | 规则 | 例 |
|-|-|-|
| 不生成 | 有真实素材；涉及真实产品 / 价格 / 品牌；需要准确信息；历史事件 | 主持人、实拍玩具、芯片、老广告、发布会、数据中心 |
| 代码动画（画布） | 解释机制；要逐字卡点；精确数字与流程 | 双轨磁带、计数解锁、分支树、窗口与记忆本、回声循环、情绪波形 |
| LibTV 直接生成 | 无真实素材，静态图或代码动画撑不起的**比喻与情绪镜头** | 死背台词的演员 / 撕台词本、结尾温暖陪伴 |
| 代码灰盒 → LibTV | 动作必须卡在口播某几个字上，文字抽卡卡不准 | 三棒接力（三次交棒对齐“第一棒 / 第二棒 / 第三棒”） |
| 网上找真实素材，生成兜底 | 家常动作、通用场景（水龙头、拔路由器、按键说话、关机黑屏、客厅电视、数据中心） | 先搜官方片 / 公开视频 / 素材站；找不到再用代码画布或 LibTV；**不安排补拍**（用户要高效） |

## 历史段落
坚持真实史料。先用 `archival_search.sh` 找原版广告与实物影像（1890 爱迪生玩偶就有现存实物播放影像）；只有确认找不到时才生成，并只当“情景再现”使用。

## 生成清单格式
编号 / 用在哪一镜 / 方式（文生 / 全能参考 / 代码灰盒）/ 提示词要点 / 时长与花费。
- **视频模型硬锁定（用户已定，2026-11-26）**：调用 LibTV 生成视频**一律只用 `magi-2`**（1080p 约 0.05 元/秒，质量和价格综合最划算），**严禁改用或推荐其他视频生成模型**；预算按每条 3 次重试预估。

## 提示词自检（摘自 guizang-magi2-skill）
- 高密度短句；零否定词；眼睛 / 瞳孔不与任何光源词同句。
- 音效焊在动作那半句里；不堆多种配乐乐器（配乐后期用本地 BGM）。
- 尾帧保持运动；需要同一角色连续出镜时用上一条尾帧做全能参考。
- MAGI-2 一律 `intent: "reference"`；等待超时只查 `task_status`，绝不重复提交。
- 灰盒上传前剥音轨并出 12 宫格体检图；出片后做上下对比验收。
