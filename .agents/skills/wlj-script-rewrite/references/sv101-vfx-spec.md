## 一、六大标准视效的精确参数（严禁手画廉价空心线框）

### 1. 实拍/产品 X 光聚光放大镜标注（对标《1nm》`01:59–02:19`）
> **常见偷懒错误**：在一张原图上直接画一个黄色空心圆圈加一根折线——既看不清内部零件，又像简陋 PPT。
- **正确三层物理结构**（见模板 `xray-spotlight.html`）：
  1. **底层压暗退后层**：实拍定格帧或高清产品剖面图铺满 `1920×1080`，施加 `filter: grayscale(0.75) brightness(0.42) contrast(1.06) blur(2px)`，让整体结构可见但退居背景。
  2. **圆形聚光放大镜内芯（Spotlight Loupe）**：在目标零件坐标 `(cx, cy)` 处建圆形视窗（直径 `180px–280px`），内部放置**同一张高清原图的高亮微放大版**（`filter: brightness(1.14) contrast(1.12)`，以 `(cx, cy)` 为原点 `scale(1.12)`），外圈配 `2px solid rgba(255, 255, 255, 0.88)` 与柔和辉光 `box-shadow: 0 0 32px rgba(255, 168, 0, 0.28), inset 0 0 18px rgba(255, 255, 255, 0.30)`。
  3. **极简中文短词标注**：紧贴圆圈一侧（间距 `20px`），苍耳体 `72px–96px` 纯白或 `#FFA800`（`2–5` 个汉字，**严禁叠英文幽灵字**）。
- **步进节奏**：随口播每 `1.5–2.5s` 点亮下一个聚光镜（`scale: 0.86 → 1.0, opacity: 0 → 1`，`0.28s power3.out`）；新聚光镜亮起时，前一个已点亮的聚光镜平滑降至 `opacity: 0.42`，确保全屏永远只有一个视觉焦点。

### 2. 权威报道 / 官网原文荧光笔证据卡（对标《苹果关税》`08:00`）
> **常见偷懒错误**：把小尺寸网页截图缩在屏幕中间黑底上，字小到看不清，或者干脆自己打一行字代替证据。
- **正确四步实现**（见模板 `evidence-highlighter.html`）：
  1. **高清局部裁切铺满**：截取报道或官网正文核心段落高清大图（至少 `1920px` 宽），全屏铺满，四周压柔和暗角 `radial-gradient(ellipse 78% 72% at 50% 48%, transparent 52%, rgba(8, 9, 12, 0.58) 100%)`。
  2. **极慢摄影机微推**：整段 `2.5–4.5s` 内持续线性微推 `scale: 1.00 → 1.035`（`ease: 'none'`），杜绝死图静止感。
  3. **橙色半透明荧光带横刷**：在口播念到证据关键词时，对应英文/中文原句上方覆盖一条 `background: rgba(255, 168, 0, 0.38)`（浅底用 `mix-blend-mode: multiply`，深底用 `rgba(255, 168, 0, 0.32)` + 底部 `3px solid #FFA800`），以 `transform-origin: left center` 做 `scaleX: 0 → 1`（`0.45s power2.out`）。
  4. **左上来源标 + 可选数字提炼**：左上角挂 `22px`「`画面来源：Fast Company (2015)`」3 秒后淡出；若需强化核心数字（如 `8000+`），在荧光笔刷完后才弹出苍耳体 `#FFA800` `200px+` 大字。

### 3. 近黑十字微网格原理画布（对标《1nm》`02:20` 与《脑机接口》`02:52`）
> **常见偷懒错误**：画刺眼的亮蓝/亮白大网格，或用 emoji、火柴人简笔图标摆流程图。
- **正确画布规格**（见模板 `schematic-and-chrome.html`）：
  - **底色**：锁定 `#0E0F12`。
  - **双层克制刻度纹理**：`120px × 120px` 极淡网格线 `rgba(255, 255, 255, 0.032)` + 网格交点处 `7px` 微十字准星 `rgba(255, 255, 255, 0.085)`，营造精密光学/工程仪器底盘质感，绝不抢主体。
  - **画布内主体**：优先使用**自有实拍产品/电路板的干净透明抠图**（如真实玩具、芯片、磁带照片），信号轨迹只用干净平滑的发光脉冲带（正常信号 `#FFA800`，异常/阻塞/回声 `#FF3B30`），停在同一画布 `15–25s`，内部每 `1.5–2.5s` 推进一拍。

### 4. 贯穿全片的滚动年份翻牌器（Year Odometer）
- **位置与字号**：左上角 `top: 56px; left: 68px`，苍耳体 `#FFA800` `200px`（`line-height: 1.0`，柔和底影 `0 12px 32px rgba(0,0,0,0.75)`）。
- **动效逻辑**：每位数字独立纵向滚轮（`overflow: hidden` 窗口内数字列上下滑动 `power3.inOut`）。跨度大时（如“往后将近 90 年” `1890 → 1985`）让中间年份数字在 `1.2s` 内快速滚动掠过并稳稳停在目标年份，用数字滚动本身把时间跨度演出来，彻底替代呆板的横向时间轴和 PPT 翻页。

### 5. `4:6` 主持人列要点同屏（对标《苹果关税》`15:46`，全片限用一次）
- **分割比例**：左栏精确宽 `768px`（`40%`），纯色深炭黑 `#14161A`；右栏宽 `1152px`（`60%`），放主持人比 `1-2-3` 手势的实拍中近景。
- **逐行点亮**：左栏垂直居中排 3 行要点（行距 `64px`），每行前配 `18px × 18px` 实心方块标记 + 苍耳体 `72px` 短句（`≤ 6` 字，如 `家长看得到` / `说出口前能拦` / `换配音很便宜`）。念到第 1 条才亮第 1 行（方块 `#FFA800` + 纯白字）；念第 2 条时第 1 行降为 `opacity: 0.65`，绝不提前把三条全亮出来。

### 6. `4:3` 历史老片铺满、章节卡、底部章节条与来源标
- **`4:3` 老广告/档案片无框铺满**：底层放同一视频放大 `scale(1.42)` + `filter: blur(36px) brightness(0.48)` 填满 `16:9` 两侧；中层放原始 `4:3` 视频高度 `100%` 居中（两侧叠极柔暗边过渡），保留原始胶片/磁带颗粒，**严禁套画框或人为叠假 VHS 扫描线**。
- **章节转场与章节卡（`0.3s` 黑场 + `3.0s` 章节卡）**：先切 `0.3s` 纯黑 `#000000` 配低频 Hit → 切入章节卡（背景为本章最强实拍压暗 `brightness(0.38)` 慢推 `1.00 → 1.05`；居中上方苍耳体 `#FFA800` `64px`「第 N 章」，下方 `20px` 间距排苍耳体纯白 `160px` 章节主标题）。章节卡期间隐藏底部章节条。
- **底部常驻章节条（`38px` 高）**：`height: 38px; bottom: 0`，背景 `rgba(12, 13, 16, 0.86)` + `backdrop-filter: blur(8px)`，顶部 `2px` 全片进度细线（`#FFA800`）；内部等分或按时长比例横向排各章短名，竖线 `1px solid rgba(255,255,255,0.14)` 分隔，当前章 `#FFA800` 不透明度 `100%`，其余纯白 `50%`，**零品牌块、零英文**。
- **口播字幕与左上来源标**：
  - 字幕：风雅宋 `54px` 纯白，`bottom: 66px` 居中，`text-shadow: 0 3px 14px rgba(0,0,0,0.88), 0 1px 3px rgba(0,0,0,0.92)`，无描边、无黑底盒。
  - 第三方来源标：`top: 28px; left: 36px`，`22px` 纯白 `opacity: 0.70`「`画面来源：XX`」（带极轻文字暗影保证亮底可读），镜头入场显示，`3.0s` 后用 `0.4s` 淡出至 `0`。

## 二、OpenMotion 渲染零事故硬约束

1. **未出场容器双锁**：所有镜头层 `.sv-layer` 默认必须同时声明 `opacity: 0; visibility: hidden; isolation: isolate;`，绝不只写 `visibility: hidden`（防止 `<video>` 激活时穿透父层造成 1 帧闪现）。
2. **媒体激活时序**：任何 `<video data-start="T">` 的 `T` 必须 `>=` 该镜头容器在 GSAP 中的出现时间点。
3. **动效缓动克制**：入场统一用干脆收敛的 `power3.out`（`0.22–0.32s`），严禁使用夸张弹跳的 `elastic` 或大幅度旋转飞入。
