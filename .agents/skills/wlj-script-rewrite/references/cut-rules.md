# 台词删减规则（只删不改不加）

## 能删的
- 口头禅式过渡：有意思的是 / 说出来你可能不信 / 不过别误会 / 说白了 / 明白了……之后 / 站在今天这个节点。
- “这期视频我们……”类自我介绍式废话（后面若有目录式问题，问题本身就是目录）。
- 画面已经交代的信息再口播一遍（例：89 元和 2000+ 同屏后再说“差了二三十倍”）。
- 同一件事讲两遍：保留讲得更完整、位置更合适的那一次（例：“对话拆三层”与“三棒接力赛”）。
- 全片总结句没有点到的支线（例：主线“留声机 → 磁带 → 8000 句台词”，芯片发声是支线）。
- 比喻讲完后的重复解释；像广告口号的结尾句。
- 成片里残留的口误重复；实录说错、但删掉后意思反而准确的半句。
- 首尾撞车的句式（两处“回头看这 130 年”，留一处）。

## 不能做的
- 改字、换词、调换句内语序、从别的句子拼字。
- 只删一个字（如“第”）或从词中间下刀。
- 删掉后让下一句失去主语或指代对象（删前读一遍前后文）。

## 剪口检查
1. `phrase_time.py`（用 product-video-edit 的 venv 运行）会读原音频，在每个剪口 ±0.25s 内找最安静的 80ms 测响度。Whisper 字级时间在句间常显示间隙 0，**不能**用它判断气口。
2. ≤ -40 dB：可直接剪。
3. -40 ~ -30 dB：需听验。
4. > -30 dB：连读。优先挪切点（保留句首连接词“而 / 但”），或换同一句的其他 take，或给出“退一步”的较小删法，仍不行就保留原句。
5. 删减点前后各写清遮法：换景别、切 B-roll、藏进片名卡 / 章节卡。
6. 重新排的“原声 / 音效位置”不算改台词（例：把 1890 原声挪到“声音又尖又诡异”之后）。
7. 位于章节开头、前面没有前文的删除段不存在接缝，不必按入口判定。

## 交付格式
表格列：编号 / 位置 / 原话（删除线）/ 为什么删 / 省时；另列“考虑过但保留的”及理由；再给删减后可通读的完整台词。
