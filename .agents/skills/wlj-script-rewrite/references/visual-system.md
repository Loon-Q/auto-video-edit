# 视觉总纲（未来陪伴局 · 科技解说）

## 画面来源优先级
1. 真实画面：自己的实拍、厂商官方产品片。
2. 真实史料：老广告、档案照、实物影像、报道 / 官网原文截图（荧光笔划重点）。
3. 原理画布：代码动画，只解释机制。
4. LibTV 生成：只用于比喻与情绪镜头；历史段落找不到任何真实素材才用，且不冒充档案。

## 全片只用 3 种画面状态
| 状态 | 做法 | 禁止 |
|-|-|-|
| 主持人 | 全屏出镜；4K 素材做全景 1.0 / 近景 1.3 两档，每个删减剪口换一次景别；金句停 4–6 秒 | 圆窗、无理由抠像拼贴 |
| 全屏真实画面 | 实拍与史料铺满；4:3 老片用同画面放大虚化补边，保留原始颗粒 | 画框、发光边框、额外复古滤镜、带原字幕素材 |
| 原理画布 | 全片同一张：近黑 #0E0F12 + 极淡网格；元素用实拍抠图；每 1.5–2.5s 点亮一个新东西；当前项 #FFA800，问题项 #FF3B30 | 图标堆砌、PPT 飞入、一屏多个重点 |

列要点时才用一次 4:6 同屏（主持人右移 60%，左 40% 逐行亮）。

## 字
- 只在三种情况上屏：数字与年份、反常识关键词、对比结论；每屏最多 1 组。
- 包装字：苍耳体（`04_后期通用素材/字体/仓耳体.ttf`），主字 ≥120px，年份 200px；说到那一帧才出现。
- 字幕：风雅宋，白字、柔和阴影、约 54px、底部居中，无描边无黑底；位于章节条上方。
- 主色 #FFA800，警示 #FF3B30，对比组统一白色、同高对齐。
- 禁止：英文标签、编号角标（01/03）、胶囊框、装饰线、长句说明、左下品牌牌子。

## 画面来源标注（用户已定，2026-11-26）
- **只用于第三方画面**：老广告、新闻、他人视频、官网截图。自己的实拍、原理画布、LibTV 生成不标。
- 位置左上，22px 白字（约 70% 不透明度），文字格式「画面来源：XX」，例「画面来源：Mattel 1960」。
- 该镜头出现时显示，**3 秒后淡出**；同一来源连续多镜只在第一镜标一次。

## 底部章节条（用户已定要加，2026-11-26）
- 全片常驻（冷开场结束、第一章卡之后出现），高约 38px，贴底，深色半透明底。
- 横向排列各章短名（如：背了130年的台词 / 剧本被撕了 / 肚子里的传声筒 / 尾声），当前章 #FFA800，其余白色约 50% 不透明度；可带一条随时间推进的细进度线。
- 不放品牌块、不放 Logo、不放英文。
- 字幕底边留在章节条上方（约 bottom 66px），二者不重叠；全屏片名卡与章节卡期间章节条可隐去。

## 贯穿设计
每期找一个能贯穿全片、由台词自然驱动的视觉元素，代替时间轴和翻页卡。例：《AI 对话玩具》用“会滚动的年份”（1890 → 1985 → 1998 → 2015 → 2022.11.30，尾声倒滚回 1890）。

## 剪辑与转场
- 硬切为主，切点踩重音字；不用滑入 / 翻页 / 缩放转场。
- 章节转场统一：黑场 0.3s + 低频 hit；章节卡 3s，背景用本章最强实拍压暗，小字“第 N 章”+ 大标题，不写英文 Chapter。
- J-cut：下一段声音提前 0.3–0.5s 进。
- 节奏“快—停”：开场与章节开头 1–3s 一切；金句停主持人 4–6s；原理段同一画布 15–25s，内部每 1.5–2.5s 变化。

## 声音
- BGM 只用用户本地“背景音”文件夹；每章一首；开场 ≥110 BPM，原理段选起伏小的铺底曲，尾声慢曲。
- 口播下 BGM 约 -22 dB，章节卡抬到约 -14 dB 再落；历史原声段 BGM 绝对静音。
- 音效只用真实影视库：金钱、hit、riser、按键、啸叫、断电、水滴；只给真正需要强调的点。
