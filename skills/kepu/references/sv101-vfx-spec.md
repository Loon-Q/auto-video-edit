# 硅谷101 质感视效工程参数与实现规范（V5.1 防简陋与零瑕疵铁律）

本规范从硅谷101 标杆原片（《1nm》《脑机接口》《苹果关税》）提取视觉物理参数，并融合《未来陪伴局》V5.1 审片定版标准（花字零底纹阴影、全篇常驻章节条、130年演进节点树、不透明分支树标签、三幕动态看板、`0.40s` 光学丝滑转场）。

对应的可直接复用 OpenMotion 模板位于本技能 `templates/sv101/`。

## 一、七大标准视效的精确参数

### 1. 实拍 / 剖面 X 光聚光放大镜标注（对标《1nm》`01:59–02:19`）
- **三层物理结构**（见模板 `xray-spotlight.html`）：
  1. **底层压暗退后层**：高清产品内部图或实拍定格帧铺满 `1920×1080`，施加 `filter: grayscale(0.70) brightness(0.40) blur(2px)`。若博物馆实物背面图看不出是什么（如光秃秃一块铁皮），必须先用 **Nano Banana / Imagen** 生成**正面可辨识主体的开胸结构解剖图**（如爱迪生玩偶正面打开铁皮胸腔露出黄铜齿轮与蜡筒）。
  2. **圆形聚光放大镜内芯**：在目标零件 `(cx, cy)` 处建圆窗（直径 `180px–256px`），内放同一高清原图 `brightness(1.12) contrast(1.08) scale(1.14)`，主焦点配 `4px solid #FFA800` 边框。
  3. **零阴影中文标注卡片**：紧贴圆圈一侧，深色半透明实心底 `rgba(14,15,18,0.88)` + 左侧 `4px` 色条，苍耳体 `56px–68px`，**`text-shadow: none !important`**。

### 2. 权威报道 / 官网原文荧光笔证据卡（对标《苹果关税》`08:00`）
- **四步实现**（见模板 `evidence-highlighter.html`）：
  1. 高清正文截图铺满 `1920×1080`，四周压柔和暗角 `.sv-scrim-dark`。
  2. 持续线性微推 `scale: 1.00 → 1.04`（`ease: 'none'`），杜绝死图感。
  3. 念到关键词时，以 `transform-origin: left center` 横刷橙色荧光带 `scaleX: 0 → 1`（`0.42s power2.out`）。
  4. 左上安全边距 `top: 38px; left: 48px` 挂来源标；右下弹出带清晰描边深底衬的数字提炼卡（如 `8000+条台词`，零阴影底纹）。

### 3. 近黑十字微网格原理画布：逻辑树、声学波束与三幕数据看板
- **底盘规格**：锁定 `#0E0F12` + `120px × 120px` 极淡网格线 `rgba(255,255,255,0.035)` 与交点微准星。
- **逻辑分支树（防穿字与防抽象铁律）**：
  - 严禁只画几根光秃秃曲线和一个红点！每条代表分支必须挂具体的中文问答胶囊（如 `孩子提问` → `“你最喜欢什么颜色”` → `命中台词 #3021` → `“最爱粉裙子去派对！”`，以及脱稿红虚线 `剧本外脑洞：“恐龙为什么不刷牙？”` → 红色 `✕` 断裂点 → `树枝断裂 → 岔开话题：“换个别的聊吧”`）。
  - **防穿字硬约束**：`<svg>` 连线层设 `z-index: 2`，所有 `.tree-pill` 标签卡设 `z-index: 15` 且必须使用**纯色不透明深色背景**（如 `#171a22` / `#241e12` / `#261416`，**严禁 `rgba(..., 0.15)` 半透明底导致连线像删除线一样穿过文字**）。
- **声学 / 信号场（防圆窗拼贴铁律）**：
  - 严禁把带人手的实拍小图塞进虚线圆圈里！用 Nano Banana 生成暗室悬浮产品半透明结构主体图铺底，上层叠 `<canvas width="1920" height="1080">` 实时绘制动态波束（如第一拍青色椭圆波束护盾阻挡左右红色环境杂音；第二拍底部喇叭扩散红环并沿对称弧线倒灌进顶部麦克风）。
- **多维结论三幕动态看板（防长帧干停铁律）**：
  - 当口播连续 `7–10s` 讲多维优缺点（如 `快 · 贵 · 难管`）时，**严禁一屏黑底打三个字干等口播念完**！必须按语义切分为 `2.4–3.5s` 一幕的动态仪表盘（第一幕延迟竞速条 `2100ms vs 320ms` → 第二幕算力成本条 `1× vs 15×–20×` → 第三幕有无「纯文字安检门」双通道对比）。
  - 看板顶栏主标题 `font-size: 108px; white-space: nowrap; flex-shrink: 0;`，副标题 `font-size: 28px; white-space: nowrap;`，严禁自动换行产生单字孤行。

### 4. 顶部时间线演进节点树（`#sv-era-tree`）与滚动年份
- **位置与结构**：`top: 34px; right: 48px; width: 1180px; height: 92px`，毛玻璃深色底盘内横向等距排布 `5–6` 个关键年代里程碑（年份 + 4–5 字核心机制名，如 `1890 微缩留声机` … `2022 大模型破局`），中间配 `#era-rail-fill` 橙色推进轨道。
- **状态联动**：已讲完节点标为 `.is-done`（柔和橙点），当前正在讲的年代标为 `.is-current`（放大 `1.08x` + `#FFA800` 白边发光圆点），尾声总结时全线点亮贯通。

### 5. `4:6` 主持人列要点同屏（全片限用一次）
- 左栏宽 `768px`（`#14161B`），垂直居中排 3 行要点（`18px` 橙色方块 + 苍耳体 `68–72px` 短词）；右栏宽 `1152px` 放主持人 `0.00ms` 精准同步的 4K 实拍。随口播念到第 1、2、3 点逐行滑入点亮。

### 6. 全篇常驻章节条、丝滑光学转场与安全边距
- **全篇常驻底部章节条（`42px` 高）**：`height: 42px; bottom: 0; opacity: 1` 从第 `0` 帧常驻至尾帧（含 `导语` 项与顶部 `2px` `#FFA800` 连续进度条），绝不在章节卡期间隐藏。
- **章节间 `0.40s` 光学丝滑转场（严禁 `0.3s` 黑屏死切）**：将章节内画面包进 `#seam-stage`（`#sv-chapter-bar` 留在 `#seam-stage` 外部保持不动）。上一章末尾 `0.40s` 对 `#seam-stage` 做 `scale: 1.0 → 1.10, filter: 'blur(14px) brightness(0.36)'`，下一章开头 `0.45s` 对动态章节卡背景做 `scale: 1.10 → 1.03, filter: 'blur(12px) → blur(0px)'`，合成时用 `xfade=transition=fade:duration=0.40` 叠化。
- **零阴影底纹硬规则**：所有 `.sv-big-word`、章节标题、年份与数字卡片一律写死 `text-shadow: none !important; filter: none !important;`。
- **左上来源标安全边距**：`top: 38px; left: 48px`，`padding: 6px 14px`，圆角半透明深色衬底，确保在任何播放器下绝不贴边裁切。

## 二、OpenMotion 渲染零事故硬约束
1. **未出场容器双锁**：`.sv-layer` 默认写死 `opacity: 0; visibility: hidden; isolation: isolate;`。
2. **纯 GPU Transform 动画（过 Studio Linter 铁律）**：GSAP 严禁对元素直接 tween `left`、`top`、`right`、`bottom`（会触发 `gsap_non_transform_motion` 整数像素抖动报错）；位移一律用纯 `x` / `y` / `scale` / `scaleX`！
3. **本地字体显式声明**：CSS 中使用的每一个 `font-family`（含 `CangEr`、`Song`、`Sans`）必须在顶部写明 `@font-face` 指向工程 `assets/fonts/` 下的真实字体文件，通过 `lint-project.mjs` 零报错校验。
4. **媒体时长防冻帧锁**：每个 `<video>` 的物理文件时长必须严格大于 `data-duration`，且 `data-start + data-duration <= root data-duration`。
