# 视觉总纲（未来陪伴局 · 科技解说 V5.1 定版）

## 一、画面来源四级优先级
1. **真实画面**：自有 4K 实拍、厂商官方无字幕产品片。
2. **真实史料 + 博物馆级结构复原**：老广告、档案照、实物影像、权威报道/官网原文截图（配橙色荧光笔划重点）；若实物档案看不清内部构造（如铁皮背板），用 **Nano Banana / Imagen** 生成正面开胸剖面高清图配引线标注。
3. **原理画布（Canvas / SVG 动态图解）**：近黑 `#0E0F12` 十字微网格底盘，用于声学波束、逻辑分支树、实时延迟/成本/安检门看板。
4. **现代商业隐喻生成（Nano Banana 参考图 → LibTV `magi-2`）**：仅用于比喻与情绪共鸣镜头，**严禁字面直译家常俗套画面**，必须转化为现代科技商业隐喻；全片**零重复使用同一条 B-roll**。

## 二、全片只用 3 种画面状态
| 状态 | 标准做法 | 绝对禁止 |
|-|-|-|
| **主持人** | 4K 原片自然全屏出镜；利用 4K 像素做全景 `1.0x` ↔ 近景 `1.3x` 两档光学景别交替，**凡遇分句补录切口必换景别消除跳帧**；金句稳停 `4–6s` | 圆窗拼贴、无理由抠像描边、同景别硬接造成人物跳帧、话完后留低头复位帧 |
| **全屏真实画面** | 实拍与史料铺满；`4:3` 老片用同画面放大 `1.42x` 虚化补边，保留原始颗粒；每条 `<video>` 时长必须严格大于槽位时长，**严禁话没说完视频先卡死** | 画框、发光边框、带原字幕素材、半途冻帧干等 |
| **原理画布** | 近黑 `#0E0F12` + 极淡微十字准星网格；核心物件用高清去背主体 + 实时动态信号轨迹；**单幕静态停留不超过 `3.0s`**，长段落每 `1.5–2.5s` 推进一拍或切换子看板 | 简笔火柴人、半透明框被连线穿字、黑底大字干停 `5–8s` 等口播 |

列举 `1-2-3` 核心利弊要点时，全片限用一次 `4:6` 同屏（左 `768px` 深炭黑 `#14161B` 逐行点亮，右 `1152px` 主持人实拍）。

## 三、字体、零底纹花字与无标点字幕铁律
- **包装大字（零阴影底纹铁律！）**：统一使用**苍耳体**（`仓耳体.ttf`），主字 `≥ 108px`，念到该词那一帧才上屏；**强制 `text-shadow: none !important; filter: none !important;`**，严禁在花字底下留任何黑色阴影团或脏底纹！多字主副标题必加 `white-space: nowrap` 防止折行掉出孤字。
- **常驻字幕**：统一使用**风雅宋**（`风雅宋.ttf`），`54px` 纯白字 + 柔和底影，无描边无黑底盒，置于 `bottom: 64px`；**一律去掉句尾标点，句中逗号统一改用单个空格**，符合人眼现代阅读节奏。
- **锁定色值**：主高亮琥珀橙 `#FFA800`，警示红 `#FF3B30`，声学/安全辅助青 `#50EBE0`。
- **第三方画面来源标注**：仅第三方老广告、新闻、他人视频、官网截图在左上标「`画面来源：XX`」，**锁定安全边距 `top: 38px; left: 48px`**（配柔和半透明底衬，严禁贴边被裁切）。

## 四、全篇常驻章节条与时间线演进节点树
1. **底部常驻章节条（`42px` 高，`00:00` 起全篇常驻！）**：
   - 从全片第 `0` 帧（`00:00`）到最后一帧**全程 `opacity: 1` 常驻贴底**（含 `导语 | 第一章 | 第二章 | 第三章 | 尾声`），**片名卡与章节卡期间也不隐藏**，并在转场时保持绝对静止充当全片视觉锚点。
   - 顶部带 `2px` `#FFA800` 全片连续进度线（`0% → 100%`），当前激活章高亮 `#FFA800` + 底部微光，无品牌块无英文。
2. **顶部时间线演进节点树（`#sv-era-tree`）**：
   - 涉及多代历史演进（如 `1890 微缩留声机 ── 1960 拉绳唱片 ── 1985 双轨磁带 ── 1998 传感器计数 ── 2015 云端分支树 ── 2022 大模型破局`）时，在右上角 `top: 34px; right: 48px` 挂载节点树组件：已完成节点柔和橙色，当前节点高亮放大发光，连接轨道随年代推进点亮，让观众一眼看清全局坐标。

## 五、丝滑章节转场与差异化声音设计
- **章节间丝滑光学转场（告别黑屏死切！）**：
  - **严禁在章节之间插入 `0.3s` 纯黑场或静止硬切**！
  - 上一章结尾最后 `0.40s`（`12` 帧）对 `#seam-stage` 施加光学推镜模糊（`scale: 1.0 → 1.10` + `blur(14px)`），下一章开头前 `0.40s` 由 `scale: 1.10 + blur(12px)` 平滑收清至动态章节卡背景，配合 `ffmpeg xfade=transition=fade:duration=0.40` 无缝融合，而最外层的 `#sv-chapter-bar` 全程稳立不动。
- **全局连续音频母带 + 差异化音效库**：
  - 按 `48,000 Hz` 整数采样点构建全片单一连续母带：口播严格锁定各章帧起点（零累积漂移），章节接缝处配乐余弦平滑交叉淡化，并在转场前 `0.22s` 提前叠入丝滑空气感 J-cut 转场声（`silk_transition`）。
  - 同类 UI 提示音、快门音、盖章音、节点点亮音准备多组音高/音色变体轮换使用，彻底杜绝单一音效重复刷屏。
