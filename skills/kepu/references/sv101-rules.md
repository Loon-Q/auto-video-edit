## 真正该学的（比版式更重要）
1. **真实画面打底**：开场与案例几乎全是真实素材，设计元素只在讲机制时出现。
2. **快切后骤停**：4–6 个 1–2s 画面之后，在最反常识的一句停在主持人 4–6s。
3. **证据感**：网页 / 报道 / 官网截图 + 荧光笔划重点，替代“自己写一行字”。
4. **原理用真实产品画面做 X 光渐进标注**（圆圈 + 引线 + 中文标签），不用图标。
5. **章节卡**：主题画面压暗 + 粗大白字，3–4s。
6. **主持人**：自然全屏；只在列要点时用 4:6。
