# 失败教训（被用户否定过的做法与 V5.1 实战纠偏）

来源：《AI 对话玩具》V0.4 → V4 → V5 → V5.1 全流程审片复盘（2026-11-24 至 11-26）。以下每一条都是真金白银踩过的红线，后续任何一期新片必须逐条规避。

## 一、结构、画面与史料红线（V4 复盘）

| 错误做法 | 用户反馈 / 问题 | V5.1 强制标准 |
|-|-|-|
| 用文字卡、抽象 AI 图顶替实物 | 说到玩偶看不到玩偶，背景看不出是什么 | 每句先问“观众此刻该看到什么实物”；能拍就拍、有史料用史料，局部剖面缺图用 Nano Banana / Imagen 生成高清结构解剖图（如爱迪生玩偶铁皮胸腔微缩留声机剖面） |
| 每段发明一种版式（胶囊、圆窗、目录、画框、角标） | 像廉价 PPT；左上出现莫名其妙的英文小字 | 全片只用 3 种画面状态（主持人自然全屏 / 全屏真实画面 / `#0E0F12` 原理画布）；仅列举 `1-2-3` 要点时用一次 `4:6` 同屏 |
| 照抄旧脚本画面描述、台词照单全收 | 废话多、同一件事拆两章讲两遍 | 先出只删不改方案（路径 B）或零废话初稿（路径 A），再重新设计逐镜画面 |
| 开场用慢歌、字号偏小句子偏长 | 开场不抓人、字肉眼看不完 | 开场配乐 `≥ 110 BPM`，每章按情绪换曲；核心花字 `≤ 6` 字、`≥ 108px`，念到该词那一帧才出现 |
| B-roll 带原字幕 / 水印 | 与自家字幕打架穿帮 | 外部素材入库必跑 8 帧底部高危区体检图，带硬字幕的一律弃用或裁切 |

## 二、音画同步、口播气口与剪辑手感红线（V5 → V5.1 审片复盘）

| 错误做法 | 用户反馈 / 问题 | V5.1 强制标准 |
|-|-|-|
| 把重剪后的纯音频与原视频分开独立对位 | **音画不同步**，人物出镜嘴型和台词差半拍 | **4K 原片音画同源原子切片**：口播音频与所有出镜 `<video>` 必须从**同一条原生音画同步的 4K 相机母带**按 `1600 samples/frame @ 48kHz / 30fps` 帧对齐同源切出，短 GOP（`-g 15 -keyint_min 1 -bf 0`）编码，导出后必跑互相关校验（全片误差 `< 10 ms`） |
| 把前面说错半截的 NG 句头和重录的后半句拼在一起 | **台词有断断续续分裂感**，语气和重音断层 | 主播前两句说错后从头重录时，**严禁掐头去尾拼接两次不同 take**；一律整句采用**最后一次完整、干净的重录版** |
| 保留分句录制时的原始停顿，或结尾留出 1–2 秒空隙 | **气口太长**，明明写作上是连贯一段话却听着断气难受 | 按**写作语义连贯度**而非原始录音间隙收紧气口：同句分句 `0.06–0.14s`（`2–4` 帧），句末换气 `0.20–0.23s`（`6–7` 帧），严禁在句中留超过 `0.3s` 的死静音 |
| 分句补录的上下两镜直接原尺寸硬接，或说完后头部复位跳帧未切走 | **出镜人物明显跳帧**（如“顺着脑洞一直聊”后接章节卡前跳了一下） | 1. 话音落点后若原片有低头/复位动作，必须**提前在尾字收音帧切进章节卡或 B-roll**；<br>2. 分句重录的相邻真人镜头必须用 **4K 原片光学景别交替（`1.0x` 全景 ↔ `1.3x` 近景）** 消除补录拼接感 |
| 分段渲染后直接硬拼，章节间出现黑屏或死画面 | **章节衔接生硬**，要么黑屏一下、要么画面卡住不动 | **严禁章节间插 `0.3s` 纯黑场**！统一采用 **`0.40s`（`12` 帧）光学推镜动态模糊丝滑叠化（`xfade`）**，背景保持微推运动，底部章节条纹丝不动，配合 `48kHz` 整数采样全局母带与 `-0.22s` J-cut 丝滑转场音效 |
| B-roll 视频时长短于卡点槽位，话没说完画面先停住；或停顿半天再弹包装 | **视频放一半突然卡死**，观众以为播放器坏了 | 1. 每条 `<video>` 真实文件时长必须严格大于 `data-duration`；<br>2. 需要做定格解读（如“脱稿露馅”“秒变摆件”）时，**定格 `0ms` 当帧必须同步触发去色压暗与花字标注**，绝不允许先干停半秒再出效果 |
| 同一条音效或同一条 B-roll 反复出现 | **听觉与视觉单一廉价**（如数据中心、机械声重复用） | 全片**零重复使用同一条 B-roll 画面**；同类音效必须准备多组音色/音高差异化变体（如 `tick_1..3`、`node_bloom_1..3`、`verdict_stamp_1..3`）搭配定制拟音 |

## 三、包装细节、原理画布与商业隐喻生成红线（V5 → V5.1 审片复盘）

| 错误做法 | 用户反馈 / 问题 | V5.1 强制标准 |
|-|-|-|
| 大号花字/年份底下带黑色 `text-shadow` 阴影团（图1、图5） | **花字下面有没去掉的脏底纹**，严禁出现 | 所有包装大字、年份、结论词一律强制 **`text-shadow: none !important; filter: none !important;`**；对比度靠干净深色底、柔和全局暗角（`.sv-scrim-dark`）或实体描边卡片保证 |
| 章节条在冷开场或章节卡期间隐藏；缺少时间线坐标 | 章节条应该全篇都有；讲 130 年历史却看不到演进节点树 | 1. **底部 `42px` 章节条从 `00:00` 第 0 帧至全片尾帧全程 `opacity: 1` 常驻**（含 `导语` 与全片连续橙色进度线）；<br>2. 涉及历史跨度或多代演进时，顶部右侧常驻 **演进节点树 `#sv-era-tree`**，随年份实时点亮推进 |
| 左上角来源小字太靠边被裁切；字幕保留句中逗号与句末标点 | 左上角字被切掉一半；字幕标点冗余不符合人眼阅读习惯 | 1. `.sv-source-tag` 锁定安全边距 **`top: 38px; left: 48px`**；<br>2. 字幕一律**去除句尾标点，句中停顿改用单个半角空格** |
| 原理画布画空洞线条、半透明标签被连线穿过、或局部特写看不出主体（图2、图3、图4） | 图2 铁皮背板看不懂是什么；图3 只有线和红点看不懂；图4 手托圆圈莫名其妙 | 1. **图2 类结构拆解**：必须看到完整可辨识主体（如正面开胸玩偶 + 微缩留声机引线标注）；<br>2. **图3 类逻辑树**：每根树枝必须配**纯色不透明深色标签卡**（`z-index` 高于 `<svg>`，杜绝连线穿字），直观演完“正常命中 vs 脱稿断枝兜底”；<br>3. **图4 类声学/信号画布**：用去背高清主体 + `<canvas>` 实时动态波束（青色护盾挡杂音 vs 红色喇叭声波倒灌麦克风） |
| 结论段黑底大字干停 8 秒等口播念完（图5 `快 · 贵 · 难管`） | **单画面帧长太长**，没有画面变化支撑；长标题自动折行掉出孤字 | 超过 `3.0s` 的多维结论严禁一屏黑底死字硬撑！必须拆成 **`2–3s` 一拍的多幕动态数据看板**（如延迟竞速条 → 成本对比条 → 安检门双通道对比），且主副标题加 `white-space: nowrap` 严禁掉出孤字 |
| 生成素材字面直译台词（说水龙头就放厨房自来水、说三棒接力就画三个卡通机器人递棒子），或在 LibTV 里直接抽图 | **太直白土气，缺乏现代商业片隐喻质感**，画风突兀不统一 | **强制走「Nano Banana / Imagen 先出风格统一现代商业参考图 → LibTV `magi-2` 全能参考生视频」双步管线**：把口语比喻翻译成**现代科技商业隐喻**（如：哑光黑精密阀门倾泻金色 `0101` 光纤代码流、暗调建筑光廊内声波→发光文字板→暖色声浪三棒转化、厚剧本撕裂化作金色神经元 Token 粒子流） |
