# `@kepu` / `@科普` — 硅谷101级深度科技商业科普视频独立插件包

面向 **5–15 分钟真人主持深度科技/商业科普长视频（对标硅谷101）** 的 **100% 独立闭环** AI 插件与技能包，同时支持 **Google Antigravity**（原生可视化 Plugin）与 **OpenAI Codex**（跨平台 macOS + Windows）。

不用记复杂的英文模块名，装好后只需在对话框输入 **`@科普`**（或从 `@` 菜单点选 **`@kepu`**），一套总包自动识别你手头的材料并包办到底，且**未点名时绝不乱触发、不与任何其他视频技能串台**。

## 一、小白怎么用？（记住 `@科普` 一个词就够了）

全程只有 **3 个需要你点头拍板的节点**（① 飞书审脚本 → ② 试听粗剪 → ③ 验收成片）：

| 你现在手头有什么 | 你直接在对话框怎么打字 | `@科普` 自动帮你完成什么 |
|---|---|---|
| **1. 只有一个新选题，还没拍** | `@科普 帮我从零写一期《脑机接口》的脚本和分镜，找好史料发飞书给我审` | 按硅谷101冷开场黄金四拍 + 三章结构写出零废话初稿 → 全网检索无字幕真实史料 → 生成 12 节飞书原生表格等你审定 |
| **2. 口播已经拍完，想删废话重做画面** | `@科普 口播在桌面文件夹，台词只删不改，帮我重做硅谷101分镜发飞书` | 实录逐字转写 → 原音频实测每个剪口响度 → 外部素材跑 **8 帧无字幕体检** → 输出飞书删减与分镜表（审前绝不乱花钱生成） |
| **3. 飞书脚本已拍板，开始出成片** | `@科普 飞书脚本过了，按最高标准做全片导出到桌面吧` | **4K 原生音画同源切片**（全片嘴型误差 `<10ms`）→ **Nano Banana 首帧垫图 + LibTV `magi-2` 现代商业隐喻视频** → **硅谷101 V5.1 分章精渲 + `0.40s` 丝滑光学合片** → 跑通 **4 道硬核质检**后交付成片 |
| **4. 看完片子想局部微调** | `@科普 截图里这一处的包装改一下` | 精准定位对应章节 OpenMotion 子工程局部秒级重渲，无损重合成全片并复检 |

## 二、一键安装与升级

克隆本仓库后运行一行命令，自动将 `@kepu / @科普` 安装为 **Antigravity 原生可视化插件**（`~/.gemini/config/plugins/kepu`）并同步至 Codex（`~/.codex/skills/kepu`），同时自动清理本仓库早期版本的散装目录：

**macOS**
```sh
python3 install.py --global --upgrade --with-libtv
```

**Windows PowerShell**
```powershell
py -3 install.py --global --upgrade --with-libtv
```

首次在新电脑上初始化底层运行环境（自动安装 `numpy`、`faster-whisper`、`yt-dlp` 并构建固定版本 OpenMotion；若本机已有旧运行环境会自动无损复用，无需重复下载）：

```sh
# macOS
python3 skills/kepu/scripts/video_edit.py setup --with-libtv
python3 skills/kepu/scripts/video_edit.py doctor

# Windows PowerShell
py -3 skills/kepu/scripts/video_edit.py setup --with-libtv
py -3 skills/kepu/scripts/video_edit.py doctor
```

## 三、V5.1 精品内置标准一览

- **零嘴型误差 & 零跳帧**：4K 原片按 `1600 samples/frame @ 48kHz / 30fps` 音画同源原子切片；NG 重录只取最后完整遍；句内气口 `0.06–0.14s`、句间 `0.20–0.23s`；分句补录切口强制 `1.0x ↔ 1.3x` 光学景别交替。
- **全篇常驻导览与演进节点树**：底部 `42px` 章节条从 `00:00` 第 `0` 帧至尾帧全程常驻（含 `导语` 与 `#FFA800` 连续进度条）；跨年代叙事挂载右上 `#sv-era-tree` 演进节点树；章节间采用 `0.40s` 光学推镜模糊叠化 + `-0.22s` J-cut 丝滑转场，彻底告别黑屏硬拼。
- **零阴影底纹排版与自解释动态画布**：大号苍耳体花字强制 `text-shadow: none !important`，主副标题禁折行孤字；不透明问答分支树杜绝连线穿字；`<canvas>` 动态声学波束；长结论拆为三幕动态数据看板；字幕去句尾标点、句中逗号改单空格。
- **现代商业隐喻生成管线**：统一走 **Nano Banana / Imagen 高清暗调参考图 → LibTV `magi-2`（唯一锁定视频模型）现代商业隐喻视频**（如 `0101` 光纤代码水龙头、建筑光廊声波接力、剧本撕裂化为金色 Token 流），杜绝家常俗套字面直译与重复素材/音效。
